V86 – 13th Month Financial Link

13th Month Tracker is synchronized into the Expense/Financial Summary.
- Pending 13th month records create Pending company expense rows.
- Paid records create Paid company expense rows and reduce Net Profit.
- Returning Paid -> Pending reverses the financial impact.
- Financial Summary and Expense Trackers synchronize 13th month records automatically.
- Dashboard current-year totals also include synchronized 13th month expenses.
- Existing 13th month computation and tracker UI are preserved.
