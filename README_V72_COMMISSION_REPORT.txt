V72 - AGENT COMMISSION REPORT

Added:
- Admin Commission Report page
- Excel upload format:
  Agent Name | Employee ID | Total Collection | Commission Rate | Commission
- Accepts commission rate as Excel percentage (10%), decimal (0.10), or plain 10
- Validates Commission = Total Collection x Commission Rate before import
- Period-based report and totals
- Individual Commission Slip PDF
- Generate all Commission Slips as a ZIP
- Downloadable Excel template
- Commission report has no payment status
- Existing payroll/attendance/device access functions are unchanged

Example:
Juan Dela Cruz | EMP001 | 500000 | 10% | 50000
Maria Santos   | EMP002 | 380000 | 5%  | 19000
