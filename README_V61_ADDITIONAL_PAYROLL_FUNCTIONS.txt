V61 - Additional Payroll Functions

Added:
1. Payroll delete function remains available per-row and bulk.
2. Bulk Delete now selects only VISIBLE payroll rows when using the table filters. This allows filtering by Employee Name and then selecting all filtered/visible payroll records for deletion.
3. Bulk Mark as Paid: filter Employee or Payroll Status first, then use Select All Visible Payroll. Only Approved payrolls have Paid checkboxes. Selected Approved payrolls are marked Paid in one action.
4. Bulk Paid processing matches the existing single payroll Paid workflow: loan payments are allocated once and second-cutoff monthly contributions are finalized.
5. Existing payslip email features and watermark PDF generation are retained.
